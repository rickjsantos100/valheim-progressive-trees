# Progressive Trees

Progressive Trees is a Valheim mod that aims to make tree chopping feel physical and gradual. As a tree takes axe damage, its trunk will show increasingly severe damage near the impact area before transitioning into Valheim's normal falling-tree behavior.

The first milestone is a multiplayer-safe prototype with a few visual damage stages for common tree types. The project uses BepInEx and Jötunn.
